v1.3.9 — Hour Hand
[x] Silent fetch loss — trigger functions return bool, dispatch confirms before clearing bit
    - triggerXxxFetch() now returns true only when worker accepts the task
    - Dispatch only clears REFRESH_XXX bit on confirmed dispatch
    - Prevents race where bit cleared but worker busy → fetch lost forever

v1.3.6 — Catching the Solar Wind
[x] NOAA SWPC API migration — plasma & magnetometer endpoints resurrected
    - NOAA retired /products/solar-wind/plasma-*.json and mag-*.json (Apr 30, 2026)
    - Migrated plasma to /json/rtsw/rtsw_wind_1m.json with renamed fields
      (density→proton_density, speed→proton_speed, temperature→proton_temperature)
    - Migrated magnetometer to /json/rtsw/rtsw_mag_1m.json (bz_gsm/bt unchanged)
    - New endpoints return multi-MB multi-day multi-satellite payloads — far too
      large for ESP32 heap. Implemented streaming partial-read: download only the
      first 2 KB (newest data is prepended), extract the single JSON object needed,
      discard the remaining 2.7 MB. Same pattern fetchXray() already used.
    - All seven solar metrics back online: Kp, Wind, Bz, Density, X-Ray, Flares, CME
