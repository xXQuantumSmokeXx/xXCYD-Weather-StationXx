───── Future Ideas ─────────────────────────────────────────────────────────────

[ ] Lightning Strike Tracker — Blitzortung.org (RESEARCH DONE)
    - Worldwide community network, ~100 strikes/min, free non-commercial w/ attribution
    - No official REST API — WebSocket: wss://ws1.blitzortung.org/ (mirrors: ws2, ws7, ws8)
    - Handshake: {"a": 111} (value rotates server-side)
    - Each frame: single strike, LZW-compressed string (not binary). Decode starts at code 256.
      First char literal; subsequent: codepoint < 256 → literal; ≥ 256 → dict lookup
    - Strike shape: {"lat", "lon", "time", "pol", "region", "e": intensity proxy (0.15–1.0)}
    - Worker approach: Durable Object → persistent WebSocket → rolling 30-min buffer
    - Reference: fltman/lightings/server/blitzortung.js
    - ESP32 payload: {"strikes":47,"closest":3.2,"direction":"SW","minutes":5}
    - Alternative: Xweather (Vaisala) REST API, 15K free calls/mo, strike type/intensity

[ ] Power Grid Status — real-time US grid telemetry
    - Kardashev API: free hosted, no key, all 7 US ISOs (fuel mix, load, carbon, outages)
    - EIA Grid Monitor: free API key, hourly, national (demand, generation, emissions)
    - MISO Public API: public-api.misoenergy.org, 37 anonymous JSON endpoints, 30-sec res
    - ESP32 payload: GRID: 482GW | 38% Gas | 22% Nuclear | 14% Wind | 5% Solar | 60.00 Hz

[ ] Power Outage Tracking — state-by-state customers without power
    - PowerOutage.us: gold standard (97% US, ~1000 utilities, 10-min) but enterprise only
    - EAGLE Eye (DOE/ORNL): open-source, scrapes 450 utilities/15 min, 93% US — internal tool
      ⚡ User investigating if DOE exposes a public API
    - California OES ArcGIS: ✅ PROVEN WORKING (2026-08-04) — live, free, 15-min refresh
      PG&E, SCE, SDG&E, SMUD. Endpoint: services.arcgis.com/.../Power_Outages_(View)/...
    - Approach: Worker aggregates 5-10 state/utility ArcGIS endpoints → per-state counts
    - No single free nationwide API exists; must be built

[ ] Internet Outage Monitor — BGP route monitoring, carrier status
    - Sources: Cloudflare Radar, ThousandEyes, DownDetector
    - Answers "is it just me, or is the internet down?"

[ ] GPS / GNSS Status — WAAS/DGPS corrections, satellite count, dilution of precision
    - Tactical: knowing whether GPS is degraded before relying on it

[ ] Cell Tower Status — nearby tower proximity, carrier signal context
    - Sources: OpenCelliD, carrier APIs

[ ] NWS Watches & Warnings (Expanded) — flood, tsunami, tornado, hurricane watches
    - Already pulling active alerts; expand to pre-event watches

[ ] Disaster Declarations — FEMA, state of emergency, evacuation zones
    - Sources: FEMA API, state emergency management feeds

[ ] Aviation — NOTAMs & TFRs near location
    - TFRs often precede news: VIP movement, wildfire air ops, disaster response
    - Sources: FAA NOTAM API, SkyVector

[ ] Aviation — ADS-B Traffic Density
    - Pattern disruption as signal: sudden silence (ground stop) or unusual clustering
    - Sources: ADS-B Exchange API, OpenSky Network

[ ] ISS Pass Predictor — api.open-notify.org (free, no key)
    - Upcoming visible ISS passes: time, duration, elevation, direction for next 3-5

[ ] Starlink Trains — visible satellite train predictions
    - Satellite tracking APIs or TLE-based orbital prediction

[ ] Project rename — CYD-Weather-Station → Sentinel (leaning) or TerraSentinel
    - Dropping "CYD" for future ports (larger screens, other boards)
    - Both names hardware-agnostic, one-word, honest about what the device does
